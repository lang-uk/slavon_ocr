Run experiments in parallel whenever possible — kick off background tasks and work on the next thing while waiting. Don't ask for permission on every step; make reasonable choices and report results.

**Why:** The user iterates fast and wants maximum throughput per conversation. Asking "should I do X?" when the answer is obviously yes wastes a round-trip.

**How to apply:** When the user says "do X", also consider what Y naturally follows and start both. When presenting results, lead with the data table, then the analysis. Save the "what should we do next" question for genuine decision points, not routine execution steps.
